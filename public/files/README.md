Files that go with an assignment (templates, briefs you have permission to share, checklists you wrote).
Put the file here, then list it on the assignment in `src/data/deadlines.js`:

    files: [{ label: 'Report template', file: 'report-template.docx' }]

Only add material you own or are allowed to share. Course slides and instructor documents are usually
protected by copyright, so link to where they live on your course platform instead of copying them.
